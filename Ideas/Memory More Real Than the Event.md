# Memory More Real Than the Event

## Overview

The event cannot outlast its moment; the memory can. Nothing physical transcends the instant in which it happens, so what endures of any experience is the record kept of it, and by a strange inversion of common sense the memory turns out more real and more lasting than the event it recalls. Permanence belongs to mind alone. So the soul is a ledger rather than a filmstrip: it preserves the compressed significance of what happened, and the perishable happening itself is already gone.
