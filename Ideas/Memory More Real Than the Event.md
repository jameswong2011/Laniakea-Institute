# Memory More Real Than the Event

## Overview

The event cannot outlast its moment; the memory can. Because nothing physical transcends the instant in which it happens, what endures of any experience is the record kept of it — and so, in a strange inversion of common sense, the memory is more real, more lasting, than the event it recalls. Permanence belongs to mind, not to matter. This is why the soul is a ledger rather than a filmstrip: it preserves the compressed significance of what happened, not the perishable happening itself.
