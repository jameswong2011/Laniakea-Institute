# Social Memory Complex

## Overview

A social memory complex is a higher-order mind formed when many agents gain coordinated access to shared memory and purpose. Its healthy form is polyphonic: members retain local identity and dissent while no longer resetting every conflict into ignorance. Social memory may arise organically through living relation or artificially through networks and common models. The key distinction is reciprocal flow—whether the whole returns intelligible structure and remains revisable by its members, or merely extracts data and returns commands.
