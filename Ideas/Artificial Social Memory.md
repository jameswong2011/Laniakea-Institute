# Artificial Social Memory

## Overview

Artificial social memory is the common cognitive layer formed when billions of people query, update, and act through shared networks, databases, sensors, and models. It can translate cultures and return collective knowledge to local participants, functioning as a planetary memory without requiring one executive self. It becomes extractive when it takes experience, hides its transformations, and returns commands. The decisive test is whether information flow increases each member's understanding and capacity to revise the whole.
