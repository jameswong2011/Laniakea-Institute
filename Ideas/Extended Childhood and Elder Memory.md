# Extended Childhood and Elder Memory

## Overview

Extended childhood provides time for a young human to download a cumulative way of life before independent productivity. Extended old age preserves techniques, stories, warnings, and social memory beyond peak physical strength. A community therefore supports members whose immediate material output is low because their informational role is high. The pattern shows that teaching and intergenerational memory are not cultural decoration but part of the human evolutionary design.
