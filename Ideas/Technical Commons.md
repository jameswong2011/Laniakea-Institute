# Technical Commons

## Overview

A technical commons is the shared layer of source code, protocols, standards, documentation, maintenance knowledge, and public competence on which complex infrastructure depends. Cloud branding can hide dependence on small libraries and quiet maintainers no executive understands. Sovereignty therefore requires funding custodianship, preserving source and documentation, permitting audit and forks, teaching local maintenance, and preventing one vendor from becoming the sole memory of how society operates. The commons is not costless labour; it is jointly governed civilisational memory.
