# Privacy as Decision-Space

## Overview

Privacy protects the unseen interior from which an agent can compare possibilities before performing an identity for an observer. A social memory that profiles every uncertainty may coordinate efficiently while eliminating the private experiments that generate plurality. Encryption, local custody, selective disclosure, data minimisation, and a right to remain unprofiled are therefore positive cognitive infrastructure, not obstacles to collective intelligence. Privacy is strongest when it preserves choice without concealing conduct that directly violates the shared dharmic floor.
