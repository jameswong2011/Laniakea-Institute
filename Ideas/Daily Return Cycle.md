# Daily Return Cycle

## Overview

The daily return cycle compresses the architecture into ten movements: attend, feel, assay, trace, polarise, empty, choose, repair, compress, and open. It moves from awareness of a present quale through conditions and alternatives into action, settlement, retained principle, and a renewed question. Enlightenment is not exemption from the cycle but increasing recognition of its grammar while events unfold, so less suffering is wasted on mistaken separateness or unexamined repetition.
