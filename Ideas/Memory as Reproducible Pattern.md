# Memory as Reproducible Pattern

## Overview

An event occurs once, but its pattern can be replayed, taught, compared, and used to shape later action. Memory can therefore outlast the occurrence without preserving it intact. Emotion, attention, trauma, repetition, and later interpretation determine what is retained and how it is retrieved. Permanence belongs to renewed pattern rather than frozen matter; memory is a compression that becomes real again only when a present system decompresses it into experience or action.
