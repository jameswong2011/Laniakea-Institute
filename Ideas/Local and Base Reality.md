# Local and Base Reality

## Overview

Local reality is the rule-bound environment accessible to a given consciousness; base reality is a layer not rendered by a parent of the same dimensional order. The distinction is relational because a base for one simulation may remain a local world inside a higher body. Continuous bases, discrete local renders, and emergent quanta can coexist across different levels of the same architecture.
