# Lemniscate and the Helix

## Overview

Stand at the crossing-point of the infinity symbol — the lemniscate, the sideways figure-eight. Its nexus means arriving at the same place from a new angle, with the memory of the previous pass pruned away; it encodes reincarnation, non-self, and cyclical time in one clean geometry, the loop whose amnesia keeps each choice genuine. But a mere loop only repeats. A true infinity would not close; it would rise a little with every turn — a helix rather than a circle, each return arriving one density higher. The figure is corrected from repetition into ascent.
