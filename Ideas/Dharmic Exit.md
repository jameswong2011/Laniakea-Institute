# Dharmic Exit

## Overview

Dharmic exit is a truthful path of withdrawal, closure, and reintegration from a constructed world, collective mind, enhancement system, or moral community. It requires advance knowledge of consequences, portable identity and memory where appropriate, continued access to basic life conditions, and a destination not secretly controlled by the system being left. Exit is dharmic rather than merely adversarial when it settles obligations and protects others from abandoned harms without using those obligations as a pretext for captivity.
