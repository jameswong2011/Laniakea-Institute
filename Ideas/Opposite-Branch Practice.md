# Opposite-Branch Practice

## Overview

Opposite-branch practice interrupts a repetitive prediction by constructing its plausible contrary. If the mind predicts abandonment, it imagines a realistic repair; if it expects effortless rescue, it imagines the responsibility rescue would demand; if it condemns another, it reconstructs the morality from which the act seemed necessary. The exercise does not require believing the opposite. Its purpose is to restore representation of more than one branch so the original thought no longer functions as destiny.
