# Dharmakaya

## Overview

Dharmakaya is the reality-body in which laws, agents, experiences, and nested sub-bodies meet. It is not only a remote absolute: universes, planets, organisms, institutions, and minds can be treated as sub-dharmakayas participating in a larger body of patterned collaboration. This framing makes moral scale explicit. An action may benefit one local body while injuring the wider body that sustains it, so ethical judgement asks which dharmakaya bears the result.
