# Hyperstition

## Overview

Hyperstition is a narrative that helps cause the world it describes. An image receives attention, becomes emotionally invested identity, coordinates behaviour, and materialises as institution or technology; the altered world then makes the original image appear prophetic. Advertising, ideology, ritual, design, political myth, and science fiction all use versions of this loop. The key question is not only whether a story is true now, but what kind of chooser will exist if it succeeds.
